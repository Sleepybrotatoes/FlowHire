# ATS SaaS Project

## Goal
Build a simple ATS for small teams with a Kanban pipeline UI.

## Tech Stack
- Next.js frontend
- Express backend
- PostgreSQL + Prisma
- Tailwind CSS

## Features (MVP)
- Jobs
- Candidates
- Applications pipeline (Kanban)
- Drag & drop stage movement
- Email auto-response

## Database
- users
- organizations
- jobs
- candidates
- applications
- interviews

## UI
- Kanban board with stages:
  - Applied
  - Screening
  - Interview
  - Offer
  - Rejected
